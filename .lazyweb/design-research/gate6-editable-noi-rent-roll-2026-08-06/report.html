Design research · 2026-08-06

직접 편집·상호 연동형 렌트롤과 물류센터 NOI

이전의 복합 셀·원장 중심 제안을 폐기하고, 렌트롤 참고 엑셀의 실제 항목, 기존 Supabase E.NOC 식, 한국부동산원·한국신용평가·국내 물류 리츠 공시를 기준으로 다시 설계했습니다.

결론

모든 원천값 직접 편집

제목과 자동 계산행을 제외한 자산·펀드·대출·임대차·공간·임대료·NOI 계정값은 셀에서 수정하고 포커스를 벗어나면 Supabase primary readback까지 수행합니다.

렌트롤 한 셀 한 값

면적, 기간, 총액/평당, Rent Free, 인상률/주기/다음 일자를 각각 독립 열로 둡니다. 임차인명은 선택목록이 아닌 직접 입력입니다.

NOI 3단 구조

자산 NOI, CAPEX 반영 자산 NCF, 금융비용 반영 부채상환 후 현금흐름을 섞지 않고 단계별로 보여줍니다.

스크롤

손익표 내부에 임의의 세로 스크롤을 만들지 않습니다. 페이지 세로 스크롤을 쓰고, 기간 열이 넓을 때만 기존 표 방식의 가로 스크롤과 고정 헤더·고정 첫 열을 사용합니다.

NOI 1차 자료

출처확인 내용적용
한국부동산원NOI=유효조소득-운영경비. 월세·보증금운용·실비·관리비와 청소·시설유지·수도광열·주차·제세공과·보안·조경·임대관련·일반관리비를 구분합니다.EGI와 자산 OPEX의 공식 기준
한국신용평가 CMBSNCF는 NOI에서 CAPEX를 빼고 비현금비용을 더합니다. 정의가 목적별로 달라질 수 있어 버전 관리가 필요합니다.NOI→NCF→부채상환 구조와 formula version
우리로지스 리츠임대료·관리비수익, PM/FM, 수선유지, 수도광열, 세금과공과, 보험, AMC, 보관, 사무수탁의 실제 계정이 확인됩니다.물류센터 계정과목의 구체화

권장 본표

잠재 임대료 + 잠재 관리비 + 실비회수 + 보증금운용 + 부대수익
= 잠재총수입(PGI)
- 공실손실 - 렌트프리 - 대손 - 기타손실
= 유효조소득(EGI)
- PM/FM/수선/수도광열/청소/보안/조경·제설/세금/보험/운영비
= NOI
- CAPEX/TI/LC/유보금/AMC·보관·사무수탁 + 비현금비용 가산
= 자산 NCF
- 이자 - 원금 - 대출수수료
= 부채상환 후 현금흐름

저장·연동 흐름

담당자 셀 수정 → 포커스 아웃 → 권한·revision 검사 → Supabase 원천값 저장
→ 감사로그·legacy projection → primary readback → 홈·만기·NOI 재계산 → 저장됨 표시

금지 패턴

복합 셀

㎡와 평, 개시일과 만기일, 총액과 평당, 인상률과 주기처럼 서로 다른 값을 한 셀에 넣지 않습니다.

계산행 직접 수정

NOI, EGI, NCF를 사용자가 덮어쓰면 연동이 깨집니다. 원천값 또는 감사 가능한 조정값만 입력합니다.

빈 값의 0 보간

입력되지 않은 값을 0으로 만들지 않습니다. 계산 근거가 부족하면 —로 둡니다.

내부 세로 스크롤

손익표를 고정 높이 박스에 가두지 않습니다. 기존 페이지 스크롤 흐름을 유지합니다.

리서치 한계와 검증

한국에는 법적으로 하나로 고정된 NOI 표가 없으므로 위 구조는 공공기관 산식, 신용평가 방법론, 물류 리츠 실제 계정을 결합한 Gate 6 전용 versioned 표입니다. 최종 구현은 엑셀 열·Supabase 계산·운영 readback·세 deep link 스크린샷으로 다시 검증합니다.
