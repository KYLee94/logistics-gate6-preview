# Gate 6 홈 건축물대장 연결 v11 명세

## 문제

운영 `building-register/summary` 캐시에 공식 건축물대장 값이 있어도 기존 자산의 연면적과 캐시의 연면적을 완전 일치로 비교해, 반올림 차이만 있어도 홈 자산 개요가 `미입력`으로 표시됩니다. 아레나스양지는 기존 349,722㎡와 공식 캐시 349,722.27㎡의 0.27㎡ 차이 때문에 연결되지 않았습니다.

## 읽기 계약

1. 캐시에 `asset_id`가 있으면 해당 자산의 공식 캐시를 우선 사용합니다.
2. 과거 캐시처럼 `asset_id`가 없으면 대지면적과 연면적 차이가 각각 1㎡ 이하이고 사용승인일이 같은 후보만 고려합니다.
3. 두 자산 이상에 걸리는 후보는 자동 연결하지 않습니다.
4. 여러 동·여러 필지처럼 단일 캐시 행을 전체 자산으로 확정할 수 없는 경우 추정 합계를 만들지 않습니다.
5. 건축물대장에 없는 용도지역과 임대가능면적은 임의로 생성하지 않습니다.

## 출처 계약

- 값이 없으면 해당 provenance도 `null`이어야 합니다.
- 건축면적, 주용도, 건폐율, 용적률, 구조, 주차, 준공일 등 화면 필드마다 실제 선택된 원천을 반환합니다.
- 기존 `ll_assets` 원천값은 수정하지 않고, 고유하게 검증된 캐시 행의 `asset_id`/`asset_name` 메타데이터만 보강합니다.

## 완료 조건

- 아레나스양지 운영 `v2/home/read`에서 건축면적 56,207.4㎡, 주용도 창고시설, 건폐율 59.96%, 용적률 197.13%, 구조, 주차 1,185대가 primary 응답으로 반환됩니다.
- 19개 자산 전수 결과에서 임의 추정값과 잘못된 provenance가 0건입니다.
- SQL 계약 테스트, Edge 검사, 프론트 빌드, 운영 readback을 모두 통과합니다.
