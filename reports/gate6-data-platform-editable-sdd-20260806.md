# Gate 6 전면 편집·렌트롤·NOI SDD

작성일: 2026-08-06
대상: `/data-platform/home`, `/data-platform/rent-roll`, `/data-platform/income-expense`

## 1. 공통 저장 계약

- 제목, 열 이름, 계산식 설명은 편집 대상이 아니다.
- 자산·펀드·수익증권·대출·임차인·임대차·공간·임대료 조건·NOI 원천 계정의 값은 권한 있는 담당자가 직접 편집한다.
- 홈은 읽기 화면이 기본이다. 우상단 `수정`을 누른 경우에만 입력칸을 표시하고, `저장` 시 바뀐 값 전체를 한 번의 batch로 저장한다. `취소`는 서버 값을 다시 표시한다.
- 렌트롤·수익비용의 텍스트·숫자·날짜 셀은 입력 후 포커스를 벗어날 때 즉시 저장한다. 저장은 사용자 JWT, 자산 권한, `client_request_id`, 예상 revision을 사용하며 같은 트랜잭션 안에서 감사기록과 readback을 완료한다.
- 낙관적 화면만 성공으로 표시하지 않는다. Supabase primary readback이 끝나야 `저장됨`으로 표시한다.
- 계산값과 집계값은 원천값에서 자동 산출하며 직접 덮어쓰지 않는다. 조정이 필요하면 원천 계정의 조정값과 사유를 별도 저장한다.
- 렌트롤 변경은 홈 임차현황·임대차 만기·NOI 자동원천에, 대출 변경은 홈·대출 만기·부채상환 후 현금흐름에 같은 source revision으로 전파한다.
- 읽기·저장 오류는 본문에 기술 원문이나 빨간 상태문구로 남기지 않는다. 한국어 팝업으로 안내하고, 닫으면 기존 정상 화면을 유지한다.
- 루트 URL과 로그인 완료 후 별도 복귀 경로가 없을 때의 기본 진입점은 `/data-platform/home`이다. 인증 상태를 확인하는 동안에는 기존 플랫폼 홈·업무보드를 렌더링하지 않는다. 기존 로그인 이력 기록·조회·모달 기능은 그대로 유지한다.

## 2. 렌트롤 계약

### 한 셀 한 값

다음 열은 각각 독립된 셀을 사용한다.

1. 순서, 임대상태, 임차인명, 사업자등록번호
2. 용도(저온·상온·복합·사무실), 세부 용도, 보관물품, 층, 구역
3. 전용면적(㎡), 공용면적(㎡), 임대면적(㎡), 임대면적(평), 전용률
4. 계약일, 임대개시일, 임대만기일, 운영개시일
5. 보증금 총액, 보증금 평당
6. 월 임대료 총액, 임대료 평당, 월 관리비 총액, 관리비 평당
7. E.NOC(자동계산)
8. Rent Free 개월, Rent Free 시작일, Rent Free 종료일
9. 보증금 인상률, 인상주기, 다음 인상일
10. 임대료 인상률, 인상주기, 다음 인상일
11. 관리비 인상률, 인상주기, 다음 인상일
12. Fit-out 개월, Fit-out 금액, TI 금액, 인테리어 지원금, 팔레트랙 사용료
13. 임차인 부담조건, 임대인 부담조건, 갱신조건, 중도해지조건, 원상복구조건, 채권·담보조건, 비고

임차인명은 사람이 쓰는 법인·상호명을 직접 입력한다. 내부 UUID나 key는 화면에 노출하지 않는다. 기존 행의 임차인명을 고치면 tenant master와 연결된 화면이 함께 갱신되고, 신규 이름은 서버가 결정적 tenant key를 만든다.

### E.NOC

기존 Supabase 계산을 그대로 사용한다.

`E.NOC = (월 임대료 총액 + 월 관리비 총액) / (임대면적 ㎡ × 0.3025)`

- 임대면적이 없거나 0이면 값은 `—`이며 0으로 만들지 않는다.
- 서버 계산을 진실 원천으로 하며 브라우저에서도 같은 식을 미리 보여준다.

## 3. 한국 물류센터 NOI 계약

한국부동산원의 NOI 정의, 한국신용평가 CMBS NCF 구조, 우리로지스 리츠 실제 계정을 결합한다.

### 계정 순서

- 잠재총수입(PGI): 잠재 임대료, 잠재 관리비, 실비·공과금 회수, 보증금 운용, 주차·야드, 지붕태양광·안테나, 기타 부동산수익
- 수입손실: 공실, 렌트프리·인센티브, 미수·대손, 기타 수입손실
- 유효조소득(EGI): `PGI - 수입손실`
- 자산 운영경비: PM, FM, 수선유지, 수도광열, 청소, 보안, 조경·제설, 주차·야드관리, 재산세·제세공과, 보험, 경상 임대운영, 일반관리, 기타 운영경비
- NOI: `EGI - 운영경비`
- NOI 아래선: CAPEX, TI, 임대중개수수료, 자본유보금, AMC, 자산보관, 사무수탁, 기타 소유자비용, 비현금비용 가산
- 자산 NCF: `NOI - 아래선 현금비용 + 비현금비용 가산`
- 금융: 이자, 원금, 대출수수료
- 부채상환 후 현금흐름: `자산 NCF - 금융`

감가상각, 법인세, 매각손익, 평가손익은 NOI에서 제외한다. 임차인이 직접 부담한 실비는 수입·비용에 모두 넣지 않고, 임대인이 먼저 지출한 뒤 회수하면 회수수익과 비용을 각각 표시한다.

### 화면

- 필터 한 줄, 핵심 KPI 한 줄, 단일 NOI 손익표, 시계열, 자산 비교 순서로 배치한다.
- 손익표 내부 세로 스크롤을 만들지 않고 기존 페이지 세로 스크롤을 사용한다.
- 기간이 넓을 때만 기존 표와 같은 가로 스크롤을 사용하고 첫 열과 헤더를 고정한다.
- 빈 값은 `—`이며 0으로 보간하지 않는다.
- 기본 본표는 레퍼런스들에 공통으로 나타난 MECE 핵심 계정만 표시한다. 추가 계정은 `항목 선택` 체크박스로 표시 여부를 정하며, 숨김은 표시만 바꾸고 계산·저장 데이터는 삭제하지 않는다.
- NOI·NCF 시계열의 각 기간은 마우스 호버와 키보드 포커스에서 유효총수입, 운영비용, NOI, NCF 및 비교 자산 값을 툴팁으로 표시한다.

## 4. TDD 수용 기준

- 임차인명은 `select`가 아니라 text input이다.
- 면적·기간·금액·인상조건을 합친 복합 렌트롤 열이 없다.
- 모든 렌트롤 열을 정렬할 수 있고, 초기 정렬은 층 내림차순이다.
- E.NOC golden fixture가 기존 `0.3025` 식과 일치한다.
- 홈은 명시적 batch 저장 후, 렌트롤·NOI 원천 셀은 blur 저장 후 primary readback을 요구한다.
- 홈의 같은 엔티티에서 여러 필드를 한 번에 수정해도 최초 revision 검사는 한 번만 수행한다.
- 오류 기술 원문과 `저장 실패` 문구는 본문에 나타나지 않고 `role="dialog"` 팝업으로만 안내한다.
- 로그인 직후 첫 렌더부터 데이터 플랫폼 홈 또는 인증 확인용 빈 화면만 나타나며 기존 플랫폼 홈은 한 프레임도 나타나지 않는다.
- 로그인 이력 버튼, 모달, 최근 5건 조회, 성공·실패 기록 계약이 기존 회귀 테스트를 통과한다.
- `EGI=PGI-손실`, `NOI=EGI-OPEX`, `NCF=NOI-아래선비용+비현금가산` golden fixture를 통과한다.
- 대출 원천 변경은 NOI를 바꾸지 않고 부채상환 후 현금흐름만 바꾼다.
- 손익표 컨테이너에 내부 세로 스크롤이나 고정 높이가 없다.
