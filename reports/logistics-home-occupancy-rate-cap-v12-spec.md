# Gate 6 홈 임대율 범위 계약 v12

## 목적

- 홈 임대 운영의 임대율을 서버와 화면에서 동일하게 표시합니다.
- 임대율 표시값은 0% 이상 100% 이하입니다.
- 기존 임대차, 공간, 계약별 임대면적 원본은 변경하지 않습니다.

## 데이터 계약

- 분자는 기존 `current_contract_spaces`의 점유면적 합계를 그대로 사용합니다.
- 분모는 기존 홈 projection이 선택한 임대가능면적 또는 연면적을 그대로 사용합니다.
- API의 `occupancy_rate`만 계산 결과를 0~100 범위로 제한합니다.
- `occupied_area_sqm`, `denominator_area_sqm`, `denominator_source`는 원본 검증을 위해 그대로 반환합니다.

## 실패 차단

- 현재 배포 함수에 기존 계산 조각이 없으면 migration을 중단합니다.
- 공간·계약·렌트롤 원천 테이블에는 UPDATE를 수행하지 않습니다.
- 적용 후 함수 본문에 v12 marker가 남지 않으면 migration 전체를 롤백합니다.

## 검증

- 정적 계약 테스트에서 0~100 상한·하한과 원천 테이블 무수정 조건을 확인합니다.
- 라이브 브라우저에서 서버 임대율과 UI 접근성 값이 일치하는지 확인합니다.
- 만기 알림 및 우측 시스템 알림 검증은 읽기 요청만 허용합니다.
