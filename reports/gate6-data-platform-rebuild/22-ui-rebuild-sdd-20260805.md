# Gate 6 데이터 플랫폼 UI 재구성 SDD (2026-08-05)

## 범위

기존 플랫폼은 변경하지 않고 `/data-platform/home`, `/data-platform/rent-roll`, `/data-platform/income-expense`만 재구성합니다.

## 공통 화면 계약

- 신규 플랫폼의 화면 이동은 좌측 사이드바의 `홈 / 렌트롤 / 수익·비용` 세 항목만 사용합니다.
- 본문 상단 탭은 렌더링하지 않습니다.
- 상단 왼쪽에는 현재 화면 제목만 표시합니다. `Gate 6`과 `물류센터 데이터 관리 플랫폼` 문구는 표시하지 않습니다.
- 상단 오른쪽에는 담당 자산 선택과 만기 알림만 표시합니다.
- 계정·로그아웃은 기존 좌측 하단 계정 기능을 사용합니다.
- 데이터가 없거나 계산식이 미승인인 경우 첨부 이미지와 같은 파란색·노란색 안내 배너를 렌더링하지 않습니다.

## 렌트롤 계약

- 참고 엑셀 4개에서 확인한 계약·공간·금액·권리 필드를 하나의 가로 스크롤 표에 모두 표시합니다.
- 모든 열은 형식에 맞는 오름차순·내림차순 정렬을 지원합니다.
- 최초 정렬은 층 기준 내림차순입니다.
- 행 이동, 임대 상태, 임차인 열은 고정하고 이후 열만 가로 스크롤합니다.
- 위·아래 버튼으로 행 순서를 조정할 수 있으며 저장 payload에 순서를 포함합니다.
- 임차인 화면값은 `tenant_name`과 사업자등록번호 등 사람이 사용하는 값입니다. 내부 키는 저장용으로만 유지하고 렌더링하지 않습니다.
- 자산을 바꾸면 해당 자산의 Supabase 렌트롤을 다시 조회합니다.

## 홈 계약

- 자산 개요는 자산명, 코드, 주소, 섹터, 면적, 층수, 담당자, 취득가, 평가액을 가능한 범위에서 표시합니다.
- 펀드명·유형·전략·설정일·만기와 수익증권 투자자·약정액을 투자 현황으로 표시합니다.
- 대출은 카드 나열 대신 고밀도 표로 표시하며 대주, 약정액, 실행일, 만기, Coupon 금리, All-in 금리를 함께 표시합니다.
- 만기는 임대차·펀드·대출 3종으로 구분합니다.
- 구현 설명과 `검증이 끝난 핵심 지표가 없습니다` 문구는 표시하지 않습니다.

## 수익·비용 계약

- 원시 `월별 수익·비용·수납 원장`과 `기존 대출 원장` UI는 삭제합니다.
- NOI 단계와 실제 입력 계정을 한 표에 두고 월별 셀에서 값을 직접 입력합니다.
- 잠재총수입, 손실, 유효총수입, 운영비용, 순영업소득을 같은 표에서 계산·표시합니다.
- 다른 자산 한 곳을 선택하여 동일 기간·동일 기준으로 비교할 수 있습니다.
- 월·분기·연 집계 전환과 기간별 NOI 추이를 제공합니다.
- 누락값은 0으로 꾸미지 않고 빈 값 또는 `—`로 표시합니다.

## 테스트 계약

- 소스 계약 테스트는 금지 문구 부재, 좌측 3개 경로, 상단 공통 요소, 렌트롤 정렬·고정열·행 이동, 홈 투자·대출 필드, NOI 비교·시계열을 검사합니다.
- 브라우저 테스트는 세 deep link의 직접 접속·새로고침, 좌측 현재 위치, 상단 탭 부재, 금지 안내 배너 부재를 검사합니다.
- 기존 `/`, `/work-platform`, `/home` 화면 회귀가 있으면 실패입니다.
