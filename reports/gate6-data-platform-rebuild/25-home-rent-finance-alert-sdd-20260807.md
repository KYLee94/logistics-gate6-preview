# Gate 6 홈·렌트롤·수익비용·만기 알림 SDD

- 기준일: 2026-08-07 (KST)
- 대상 경로: `/data-platform/home`, `/data-platform/rent-roll`, `/data-platform/income-expense`
- 원칙: 기존 화면과 `public.ll_*`를 삭제하지 않으며, 화면에는 운영 Supabase의 실제 값만 표시한다. 표본·추정값은 만들지 않는다.

## 1. 홈 화면 계약

상단 자산 브리프는 하나의 외곽 영역 안에서 다음 세 개 세로 열로 구성한다.

1. 자산 개요: 주소, 용도지역, 대지면적, 건축면적, 연면적, 임대면적, 용도, 건폐율, 용적률, 층수, 구조, 주차대수, 준공연도 중 기존 원천에 존재하는 값만 표시한다.
2. 임대 운영: 임대율 진행 표시, 임차인 수, 점유·공실·입주예정 공간 수, 임대면적, 월 임대료, 월 관리비, E.NOC를 정렬된 두 열로 표시한다. 월 임대료와 월 관리비는 총액과 임대면적 기준 평당 금액을 함께 표시한다.
3. 층별 배치: 기존 자산 화면에서 사용하던 stacking plan과 층 정렬 규칙을 공통 모듈로 재사용한다. 현재 렌트롤이 있으면 최신 렌트롤을 우선하고, 없으면 기존 자산 stacking plan을 사용한다.

자산 코드, 섹터, 기준 통화, 담당팀, 취득가, 현재 평가액은 이 영역에 표시하지 않는다. ㎡는 정수로, 평은 `㎡ × 0.3025`를 계산한 뒤 소수점 첫째 자리에서 반올림한 정수로 표시한다. 값이 없는 임대율은 대시 문자로 대체하지 않고 미입력 상태를 명시한다.

## 2. 렌트롤 계약

- 사용자가 직접 입력하는 모든 금액 필드는 편집 중에도 세 자리마다 쉼표를 표시하고, 저장 payload에는 쉼표를 제거한 숫자 의미를 보낸다.
- 렌트프리는 단일 시작일·종료일 열 대신 `상세 입력` 버튼을 사용한다. 팝업에서 여러 제공기간의 시작일과 종료일을 추가·삭제하며 `rent_free_schedule` 배열로 저장한다. 총 렌트프리 개월 수는 기존 계산과의 호환을 위해 함께 유지한다.
- Fit-out은 시작일과 종료일을 각각 저장한다. 기존 `fit_out_months`는 두 날짜가 있으면 계산값으로 제공하되 과거 원천값을 임의로 지우지 않는다.
- 기존 인상률 원천은 비율값이다. 예를 들어 DB의 `0.03`은 화면에서 `3%`, `0.015`는 `1.5%`로 표시한다. 새로 입력한 `3%`는 DB에 `0.03` 의미로 저장하여 기존 계산 계약을 보존한다.
- 연장갱신권과 중도해지권의 기존 `N`은 화면과 API에서 `없음`, `Y`는 `있음`으로 정규화한다. `기타 N` 같은 표현은 만들지 않는다.
- 렌트롤 저장은 저장 버튼을 눌렀을 때만 실행한다. 입력 중에는 원격 저장이나 오류 팝업을 호출하지 않는다.

## 3. 수익·비용 계약

- 상단 첫 행은 좌측 `NOI·NCF 시계열`, 우측 `기간 누계 자산 비교`의 두 열이다. 월별 NOI 입력표보다 먼저 배치한다.
- 누계 기간은 최근 1개월, 3개월, 6개월, 1년, 직접 지정을 지원한다. 직접 지정은 시작월과 종료월을 받는다.
- 비교 자산은 하나가 아니라 여러 자산을 선택할 수 있다. 선택 자산마다 동일 기간·시나리오·회계 기준으로 누계한다.
- 기본 표시 계정은 제공된 NOI 참고자료에서 반복 확인되는 임대수익, 관리비수익, 기타수익, PM, FM, 수선유지, 수도광열, 보험, 재산세·제세공과, 기타 운영경비를 포함한다. 비활성 계정은 기존 hierarchy의 하단으로 내려가고 입력을 막는다.
- 운영 원장에 입력된 값이 없으면 차트와 비교표는 0을 표본처럼 그리지 않고 비어 있는 상태를 유지한다.

## 4. 만기 알림 계약

- 신규 플랫폼의 알림은 우상단 인앱 만기 알림이다. 이메일 발송은 이번 범위에 포함하지 않는다.
- 선택 자산 기준 오늘부터 365일 안의 활성 임대차·펀드·대출 만기를 집계한다.
- 목록에는 내부 UUID나 key가 아니라 임차인 기업명, 펀드명, 대출 트랜치·대주 요약과 만기일을 표시한다.
- 행을 누르면 유형별 상세 팝업을 표시한다. 임대차는 계약·면적·임대료·권리조건, 펀드는 설정·전략·지분, 대출은 대주·약정액·잔액·금리를 표시한다.
- 원천인 임대차 종료일, 펀드 만기일, 대출 만기일이 변경·삭제되면 DB 트리거가 만기 projection과 자산 범위를 즉시 갱신하거나 취소한다.
- 알림은 해당 자산 읽기 권한이 있는 사용자에게만 노출한다.

운영 기준점 조회 결과는 활성 만기 111건(임대차 44, 펀드 16, 대출 51), 원천과 projection 불일치 0건, 자동 동기화 트리거 3개이다. 안성 홈플러스 중부허브 물류센터는 365일 이내 대출 만기 2건이 Edge API에서 primary 응답으로 확인되었다.
