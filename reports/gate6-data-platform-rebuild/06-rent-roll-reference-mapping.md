# 렌트롤 UI 참고자료 구조 매핑 SDD

## 1. 목적과 데이터 기준선

이 문서는 `260804_렌트롤 참고자료` 아래 4개 Excel 파일, 14개 시트에서 **열 구성·화면 서식·붙여넣기 검증 방식만** 참고하기 위한 UI SDD입니다. 실제 임차인명·금액·날짜·면적 값은 기록하거나 사용하지 않습니다.

> **운영값 기준선:** 실제 운영 데이터의 canonical source(최종 기준)는 `public.ll_*`입니다. 참고 Excel은 `public.ll_*` 값을 이관·보충·수정·보정하거나 자산과 연결하는 원천이 아닙니다.

### 1.1 원천 분류

| 자료 | 분류 | 허용 용도 | 금지 용도 |
|---|---|---|---|
| 아래 4개 렌트롤 참고 Excel | `ui_reference_only` | 열 그룹, 헤더 계층, 화면 서식, 선택 필드, 붙여넣기 검증 설계 | import, backfill, 운영값 보정, 자산 매핑, 계약 생성, 계산 기준값 |
| 이전 임대차 Excel `★ 260414_물류센터 임대차계약 DB_취합본.xlsx` | `historical_provenance` | 과거 자료의 존재와 구조를 설명하는 이력 증거 | import, backfill, 운영값 보정, 자산 매핑, 신규 운영값 생성 |
| `public.ll_*` | `canonical_operational` | 운영 조회·편집·검증·저장 후 readback의 기준 | Excel 값으로 덮어쓰기 또는 자동 보정 |

어떤 Excel도 현재 운영값의 진실원천이 아닙니다. Excel 파일명·시트명·셀 위치·수식·숨김 상태를 근거로 운영 자산·임차인·계약을 생성하거나 연결하지 않습니다.

### 1.2 포함·제외 범위

- 포함: 파일 무결성 표식, 사용 범위, 병합·숨김·수식 구조, 렌트롤 헤더 좌표, 공통/선택 필드, 범용 열 그룹, UI 편집·표시·붙여넣기 검증 규칙
- 제외: 원본 셀값, 운영 데이터 이관, 운영값 보정, 자산 연결, DB backfill, Excel round-trip, 손익·CAPEX·토지·평면 배치 데이터 처리
- UI 원칙: 참고 Excel의 시각적 장점을 공통 화면 구조로 바꾸되, 화면에 표시되는 실제 값은 `public.ll_*`에서 조회한 값만 사용합니다.
- 비추정 원칙: 파일 간 문구·열 위치·병합 모양이 비슷하더라도 의미가 같다고 자동 확정하지 않습니다.

## 2. 조사 방법과 파일 식별

### 2.1 구조 용어

- `실제 사용 범위`: 값 또는 수식이 존재하는 셀의 최소 사각형
- `선언 범위`: Excel worksheet dimension으로, 서식만 적용된 빈 셀을 포함할 수 있음
- `상세 후보 범위`: 헤더·합계·주석을 제외한 화면 행 구조 참고 구간
- `원천 좌표`: A1 표기법의 물리 셀 주소. 이 문서에서는 UI 설계 근거를 재확인할 때만 사용

실제 사용 범위와 상세 후보 범위는 **화면 구조를 분석하기 위한 좌표**입니다. 이 범위를 데이터 수집 또는 운영 반영 범위로 사용하지 않습니다.

### 2.2 참고 파일 SHA-256

## 7. UI 편집과 붙여넣기 계약

### 7.1 행과 계약·공간 표시

1. 화면 한 행은 API가 제공한 렌트롤 projection을 표시하며, Excel 행을 복제하지 않습니다.
2. 한 계약에 여러 층·구역이 있으면 계약 셀을 세로 병합하지 않고 행 그룹·펼침 구조로 표시합니다.
3. 웹 그리드 데이터 셀에는 Excel식 병합을 적용하지 않습니다. 정렬·필터·붙여넣기에서 행 의미가 사라지기 때문입니다.
4. Excel 예시의 세로 병합은 UI 계층을 이해하는 참고일 뿐, 빈 셀을 이전 행 값으로 자동 채우는 규칙이 아닙니다.
5. 합계·주석·빈 서식행은 편집행이 아닙니다.
6. 자산은 현재 화면에서 선택한 `public.ll_*` canonical 자산 문맥으로 고정하며, workbook 또는 파일명과 연결하지 않습니다.

### 7.2 공실

- `occupied | vacant | unknown`을 구분해 표시합니다.
- 빈 임차인명만으로 공실을 추정하지 않습니다. canonical 상태값이 없으면 `unknown`으로 표시합니다.
- 공실의 임대료·보증금·관리비를 자동으로 `0`으로 바꾸지 않습니다.
- 공실행 편집 시 자산·공간은 필요하지만 임차인·계약 필수 여부는 점유 상태에 따라 검증합니다.

### 7.3 ㎡와 평

- 면적은 ㎡와 평을 함께 표시할 수 있으며 단위를 헤더에 명시합니다.
- 한 단위를 입력하면 승인된 formula registry로 다른 단위를 계산합니다. 참고 Excel의 수식을 복사하지 않습니다.
- 두 단위를 모두 붙여넣으면 승인된 허용오차를 검증하고, 차이가 크면 저장 전에 오류를 표시합니다.
- 전용·공용·총 면적이 모두 있는 입력은 `전용 + 공용 = 총`을 검증합니다.
- 총 면적만 있는 입력에서 전용·공용을 임의 배분하지 않습니다.

### 7.4 총액과 평당 금액

- 보증금·임대료·관리비마다 총액과 평당 금액의 입력값/계산값을 시각적으로 구분합니다.
- 둘 다 붙여넣으면 면적과 승인 수식에 따른 일치 여부를 검증합니다.
- 관리비가 비어 있는 경우 `0`, `해당 없음`, `미확인` 중 어느 상태인지 사용자가 명시해야 합니다.
- 부가세, 통화, 월/연 단위, 음수 허용, 반올림 기준이 명확하지 않으면 셀 오류로 처리합니다.

### 7.5 Rent Free

- 단일 자유문구만 두지 않고 시작·종료 또는 적용월, 감면 방식, 적용 대상, 원문을 편집할 수 있는 하위 영역을 둡니다.
- 연속·분할·매년 반복·특정월 감면을 표현할 수 있어야 합니다.
- 입력 기간이 계약기간 밖이거나 감면 조건끼리 충돌하면 저장 전 오류를 표시합니다.
- Excel 문구를 자동 해석해 운영 조건을 생성하지 않습니다.

### 7.6 인상 조건

- 보증금·임대료·관리비 인상을 하나의 비율로 합치지 않습니다.
- 대상 구성요소, 인상률, 주기, 최초 적용일, 종료일, 복리 여부, 반올림 규칙, 원문을 구분합니다.
- 최초 적용일이 없을 때 계약 개시일로 자동 대체하지 않습니다.
- 중첩·공백·주기 불일치·계약기간 밖 입력은 저장 전 오류를 표시합니다.
- Excel 수식은 운영 계산에 사용하지 않고 승인된 formula registry만 사용합니다.

### 7.7 긴 특약·권리·의무

- 특약 입력은 줄바꿈과 순서를 보존합니다.
- 갱신권·중도해지권·원상복구·비용 부담은 별도 항목과 원문을 함께 표시합니다.
- 주 그리드에는 존재 여부·검토 상태·짧은 요약만 표시하고 전체 원문은 상세 drawer에서 편집합니다.
- 글자 수 제한이나 줄바꿈 손실이 생기면 저장을 막고 원문을 자르지 않습니다.
- 참고 Excel의 특약 문구를 운영값으로 복사하거나 자동 구조화하지 않습니다.

### 7.8 다중 붙여넣기

- TSV/CSV 붙여넣기는 선택 시작 셀, 대상 열 이름, 자료형, 단위를 기준으로 미리보기합니다.
- 붙여넣기 첫 행의 헤더는 표준 UI 열 이름과 정확히 일치해야 하며 임의 열 순서 추정을 하지 않습니다.
- 병합 셀은 허용하지 않습니다. 여러 행에 필요한 계약·임차인·공간 값은 각 행에 명시합니다.
- 행·열 수, 필수값, 날짜 순서, enum, 단위, 금액 기준, 특약 길이를 저장 전에 검증합니다.
- 오류가 한 셀이라도 있으면 batch 전체를 저장하지 않고 셀 위치·오류 이유·수정 방법을 표시합니다.
- 빈 문자열, `-`, 임의의 자료없음 문구를 숫자 `0`으로 바꾸지 않습니다.
- 자산 열 붙여넣기는 허용하지 않습니다. 선택된 canonical 자산 문맥과 다른 자산 데이터가 섞이는 것을 방지합니다.

## 8. 숨김·중복·수식 주의점

- Deloitte 표시 렌트롤과 숨김 초안은 서로 유사할 수 있으나, 숨김 초안의 행·열을 UI 요구사항에 중복 반영하지 않습니다.
- JLL 숨김 `O:Q`는 선택 날짜 그룹의 존재를 알려주는 UI 참고일 뿐, 운영 계약기간 열을 대체하지 않습니다.
- 병합 상위 셀을 반복 표시한 행 그룹을 서로 다른 계약으로 보이게 만들지 않습니다.
- 합계행·소계행·주석행을 일반 편집행처럼 표시하지 않습니다.
- 원본 수식은 `면적 변환/단가/기간/합계/WALE/Effective Rent` 같은 계산 열의 존재를 파악하는 참고일 뿐입니다.
- Excel 수식과 cached result는 운영 계산식·테스트 기대값·운영값 보정 근거가 아닙니다.
- 같은 이름·층·금액이 보이더라도 Excel을 근거로 운영 계약의 중복 여부를 판정하지 않습니다.

## 9. 화면 서식 통합 계약

### 9.1 표시 기준

- 열 순서는 `식별·상태 → 공간 → 계약기간 → 보증금 → 임대료 → 관리비 → 감면 → 인상 → 상세`로 고정합니다.
- 식별·상태와 공간의 핵심 열은 가로 스크롤 시 고정합니다.
- 금액·면적은 우측 정렬하고, 날짜는 저장 형식과 별개로 일관된 한국어 날짜 형식으로 표시합니다.
- `0`, `해당 없음`, `미확인`, 빈 값은 서로 다른 상태로 표시합니다.
- ㎡·평, 총액·평당, 월·연 단위를 헤더와 셀에 명시합니다.
- 사용자 입력값과 승인 수식 계산값을 시각적으로 구분합니다.
- 파일별 특수필드는 공통 열 순서를 깨지 않고 상세 drawer의 그룹으로 표시합니다.
- Excel의 병합·색상·테두리를 그대로 복제하지 않고, 다단 헤더·그룹 라벨·간격으로 정보 계층만 재현합니다.

### 9.2 접근성과 상태 표시

- 색상만으로 입력/계산, 정상/오류, 점유/공실을 구분하지 않고 텍스트·아이콘·도움말을 함께 제공합니다.
- 모든 오류는 셀 위치, 문제, 허용 형식, 수정 예시를 키보드로 확인할 수 있어야 합니다.
- drawer를 닫았다 열어도 저장 전 초안과 오류 상태가 유지되어야 합니다.
- 읽기 권한만 있는 사용자는 같은 열을 보되 입력 컨트롤이 아니라 읽기 전용 값으로 표시합니다.

## 13. 최종 금지선

`public.ll_*`만 실제 운영값의 canonical source입니다. 네 개 참고 Excel은 `ui_reference_only`, 이전 임대차 Excel은 `historical_provenance`입니다. 어떤 Excel도 이관·import·backfill·운영값 보정·자산 매핑·계약 생성·계산 기대값의 원천으로 사용하지 않습니다. 이 문서는 오직 렌트롤의 열 구조, UI 검증, 붙여넣기 서식을 설계하는 참고 계약입니다.
